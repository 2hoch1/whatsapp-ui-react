# `whatsapp-ui`

A React component library inspired by the design and interaction patterns of WhatsApp Web.

It is intended for studying UI design, component composition, interaction patterns, React development, and UI architecture, with a focus on personal experimentation, learning, and exploration.

**Notice:** Some components are still placeholders and may not be fully functional; breaking changes may occur between releases.
